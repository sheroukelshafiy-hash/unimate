UniMate - Academic AI Assistant

UniMate is an Angular project designed to assist college students with academic regulations and credit hours through an integrated RAG search system.

Features
- AI Chat Interface for answering student inquiries.
- Smart Search System using keyword-based retrieval from regulation documents.
- Clear source citations for guidelines and handbook policies.
- Built with Angular Standalone Components and Signals.

Getting Started

Prerequisites
Node.js and Angular CLI.

Installation

1. Clone the repository:
git clone https://github.com/sheroukelshafiy-hash/unimate.git

2. Navigate into the project folder:
cd unimate

3. Install dependencies:
npm install

4. Start the application:
ng serve

Open http://localhost:4200 in your browser to view the app.
